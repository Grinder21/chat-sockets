# React + TypeScript Chat App

**Demo Chat Application** built with React, TypeScript, Vite, and Express + Socket.IO for real-time messaging.

---

## 🔹 Features

- Real-time chat with Socket.IO
- Simple login with username verification (`Вася` / `Петя`)
- Protected chat page (cannot enter without a valid username)
- Message history persisted in memory (server-side)
- Responsive UI with Tailwind CSS
- Smooth scroll to latest messages
- Clean component structure (`ChatHeader`, `MessageList`, `MessageInput`)
- Loader and declarative routing with React Router v6
- Fully typed with TypeScript

---

## 🔹 Tech Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Express, Socket.IO
- Routing: React Router v6
- State: Local component state
- Build & Run: Node.js

---

## 🔹 Installation

```bash
# Clone repo
git clone <YOUR_REPO_URL>
cd <YOUR_REPO_DIR>

# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd ../server
npm install
```

---

## 🔹 Running the project

# Start

npm run dev
